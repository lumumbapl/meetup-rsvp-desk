Collect RSVPs and check in attendees at your local WordPress meetup.

== Description ==

Meetup RSVP Desk adds an "RSVP Desk" screen to wp-admin where organisers can:

* Add RSVPs with name, email, ticket type and volunteer interest
* See how many seats are taken against the venue capacity
* Check attendees in on the day with one click
* Remove RSVPs
